📖 Quran App

A Flutter application for anyone who wants to read and interact with the Quran daily.

This app is designed to help users read the Quran offline, keep track of progress, perform dhikr, and stay updated with prayer times.

🎯 Features / مميزات التطبيق

Complete Quran offline – all surahs without internet

Quick search in surahs

Resume from last verse you stopped at

Digital Tasbih for dhikr

Daily Azkar

Prayer times based on your location

Prayer notifications (under development)

Light & Dark mode

Clean code architecture using MVVM + BLoC/Cubit

Smooth animations
